     own Legacy Burn deck, receiver's authenticated login ID, watchers false.
  Both receive FlsGameCreatedMessage (960) with pending match sync.

     FlsMatchHostStartMessage (111); acceptance alone does not start the game.

  Both receive FlsMatchGameStartedMessage (2463).
  Each sends GsConnectMessage (1024) and receives GsPlayerOrderMessage (1155)
